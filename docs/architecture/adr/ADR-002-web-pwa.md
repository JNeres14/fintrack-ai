# ADR-002: Web responsiva + PWA

Status: aceita (documento técnico inicial, 06/11/2026)

## Contexto
O uso é pelo celular (câmera/galeria para enviar comprovantes) e pelo computador.

## Decisão
Uma aplicação web responsiva instalável como PWA (React + Vite PWA).

## Consequências
Um único código para celular e PC. Sem recursos exclusivos de app nativo.

## Alternativa descartada
App nativo Android/iOS (fora do escopo inicial).
